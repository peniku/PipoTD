# Créditos

## PipoTd
Projeto de Marcos (peniku). Código e documentação gerados com auxílio do Claude (Anthropic).

## Inspirações
- **Element TD / Element TD 2** (Element Studios): estrutura de jogo (elementos, camadas de torres, roda de fraquezas). Nenhum conteúdo do jogo é usado.

## System Reference Document 5.1
Parte da ambientação (nomes genéricos de criaturas e conceitos de fantasia, como lich, gigantes do gelo, urso-coruja, golem, clérigo, paladino, druida) é inspirada no **System Reference Document 5.1** ("SRD 5.1") da Wizards of the Coast LLC, disponível em https://dnd.wizards.com/resources/systems-reference-document. O SRD 5.1 é licenciado sob a Creative Commons Attribution 4.0 International License, disponível em https://creativecommons.org/licenses/by/4.0/legalcode.

PipoTd não é afiliado, patrocinado nem endossado pela Wizards of the Coast.
