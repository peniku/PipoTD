# PipoTd

Tower defense 3D com temática medieval, inspirado no Element TD 2. Feito em **Godot 4.5**.

- **Comece por aqui:** [docs/README.md](docs/README.md) (índice) e [docs/todo.md](docs/todo.md) (tarefas)
- Design do jogo: [docs/design.md](docs/design.md)
- Evolução das torres: [docs/towers.md](docs/towers.md)
- Plataforma e arquitetura: [docs/platform.md](docs/platform.md)
- Balanceamento: [docs/balancing.md](docs/balancing.md)
- Status e próximos passos: [docs/status.md](docs/status.md)

## Abrir o projeto
1. Instale o [Godot 4.5](https://godotengine.org/download). Passo a passo em [docs/setup.md](docs/setup.md).
2. No Godot: **Import** → selecione o `project.godot` desta pasta.

Os números do jogo (dano, velocidade, range, custos) ficam em `data/*.json`.
